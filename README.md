# Half Unit

Half Unit is a native iPhone and Apple Watch app for logging alcoholic drinks in one tap (in Half Unit `HU` steps of 0.5, backed by grams of pure alcohol) and tracking alcohol-free days and drinking-day statistics. Data is stored locally in SwiftData, synced via private iCloud (CloudKit), and mirrored to Apple Health on iOS.

## Setup

Generate the Xcode project (`HalfUnit.xcodeproj` is generated by XcodeGen and git-ignored):

```bash
./scripts/bootstrap.sh
```

For local device signing, edit `Config/Local.xcconfig` (created from `Config/Local.xcconfig.example`) and set `DEVELOPMENT_TEAM`. Never commit a team ID.

## Running Tests & Lint

```bash
# Fast core package unit tests on macOS
swift test --package-path Packages/HalfUnitCore

# Full test suite (HalfUnitCore + iOS app build & unit tests)
./scripts/test.sh

# Swift format lint check
./scripts/lint.sh
```

## Scripts

- `scripts/bootstrap.sh`: Sets up local xcconfig and generates `HalfUnit.xcodeproj` via XcodeGen.
- `scripts/generate_app_icon.swift`: Generates the 1024 × 1024 app icons (light, dark, tinted, watchOS) in `Resources/Assets.xcassets/AppIcon.appiconset`.
- `scripts/test.sh`: Runs core tests plus iOS and watchOS test suites.
- `scripts/lint.sh`: Runs `swift format lint`.
